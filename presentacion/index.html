Sesión 25 · Investigación

¿Qué es una tarea concurrente?

  • Es trabajo que se ejecuta a la vez o de forma intercalada con otras tareas del mismo programa.
  • En una app de escritorio, el hilo principal dibuja la interfaz; las operaciones largas van a hilos secundarios.
  • Así la ventana nunca se “congela” y el usuario puede seguir trabajando.

Sin concurrencia

Clic en “Procesar” → la ventana se bloquea → “No responde”.


Con concurrencia

Clic en “Procesar” → la tarea corre en segundo plano → barra de progreso, botón Detener y la UI sigue viva.

Tres aplicaciones que usan tareas concurrentes

Escritura + autoguardado + corrector

2. Navegador (Chrome)

Analiza el disco y protege en tiempo real sin impedir que uses la PC.

Parte 2 · Explicar

¿Qué operación ocurre en segundo plano?

AplicaciónPrimer plano (usuario ve)Segundo plano (hilo aparte)Por qué
WordEscribir y dar formato al textoAutoguardado cada pocos minutos y revisión ortográficaGuardar a disco es lento; no debe interrumpir la escritura
ChromeNavegar y leer una páginaDescargar un archivo grande (varios MB) y actualizar su progresoLa red es lenta e impredecible; la pestaña debe responder

En los tres casos el patrón es el mismo: iniciar → reportar estado → poder detener. De ahí nace el Monitor de tareas.

Parte 4 · Explicación breve

Cómo funciona el Monitor de tareas

  • Iniciar: lanza cada tarea en un hilo de fondo y activa Detener.
  • Estado: la tabla muestra progreso y estado (En espera, En ejecución, Finalizada, Detenida) actualizándose en vivo.
  • Detener: pide la cancelación de la tarea seleccionada de forma ordenada.
  • La interfaz nunca se bloquea porque el trabajo pesado no corre en el hilo de la UI.
// JavaFX: tarea en segundo plano
Task<Void> tarea = new Task<>() {
  protected Void call() {
    for (int i=0; i<=100; i++) {
      if (isCancelled()) break;
      Thread.sleep(50);
      updateProgress(i, 100);
    }
    return null;
  }
};
barra.progressProperty().bind(tarea.progressProperty());
new Thread(tarea).start();   // Iniciar
tarea.cancel();                  // Detener
Cierre

Conclusiones

  • La concurrencia mantiene la aplicación fluida mientras se ejecutan operaciones largas.
  • Word, Chrome y Windows Defender dependen de ella a diario.
  • Un buen monitor ofrece tres controles esenciales: Iniciar, Estado y Detener.
  • En JavaFX se implementa con Task, Thread y propiedades enlazadas (bind).
